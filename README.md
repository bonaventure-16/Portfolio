# Bonaventure Portfolio

A personal portfolio website for a front-end developer. The site presents an overview of the developer's skills, recent projects, and ways to contact them. It was built using HTML, CSS, Bootstrap, and JavaScript, with a simple dark mode toggle and responsive layout.

## Overview

This portfolio includes:
- A fixed top navigation bar with smooth scrolling
- A welcoming home section introducing the developer
- An About Me section highlighting key skills such as HTML, CSS, JavaScript, Git, GitHub, Bootstrap, Django, Wordpress, and React
- A Projects section showcasing multiple web apps and links to live demos
- A contact section with email and phone call actions
- A downloadable CV button
- A dark mode switch that saves the selected theme in local storage

## Features

- Responsive design for different screen sizes
- Bootstrap-based layout and styling
- Custom CSS for smooth scrolling and typography
- Theme persistence using `localStorage`
- Project cards with descriptions and external links

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Project Files

- `index.html` – page structure and content
- `portfolio.css` – custom styling and smooth scrolling behavior
- `portfolio.js` – dark mode toggle and theme persistence logic

## Run Locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
